# Project working instructions

## Scope and authorization
- This repository is for the Horizon Community Bank Banking Operations & Customer Risk Analytics project.
- Maintain documentation throughout Initiation, Planning, Execution, Monitoring and Control, and Closure.
- Do not invent business facts, requirements, metrics, data sources, decisions, approvals, or results. Mark unknowns as `Pending confirmation` and proposed content as `Draft — not approved`.
- The current authorization covers local repository scaffolding only. Do not begin technical implementation, connect to GitHub, publish, or configure remote services without further authorization.

## Documentation discipline
- Keep each phase README current with its purpose, artifact inventory, progress, open questions, and approval status as work occurs.
- Record confirmed requirements and scope in Planning; keep traceability between requirements, implementation, validation, and acceptance when those activities are authorized.
- Record decisions with date, rationale, owner if confirmed, and approval evidence. Never treat a draft as approved.
- Update PROJECT_STATUS.md when progress, blockers, next steps, or phase status changes. Update CHANGELOG.md for meaningful repository changes.
- Maintain risks, issues, changes, and progress reports under Monitoring and Control throughout the lifecycle.
- Document validation evidence and limitations. At closure, record actual acceptance, handover, lessons learned, and archival decisions.
- Keep credentials, environment files, customer information, and generated data out of Git. Use synthetic or approved sanitized examples only when authorized.
- Preserve empty tracked directories with .gitkeep; remove a placeholder when the directory gains a substantive tracked file.

## Validation
- Before reporting completion, check the requested structure, Git branch and remotes, and relevant documentation consistency.
- Report what was created or changed, what was validated, and any unresolved items. Do not claim approvals, completed analysis, or tests that did not occur.
