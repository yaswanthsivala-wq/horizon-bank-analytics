## Required approval annex for each section

Before any section may be accepted, its Project Owner reviewed annex must supply **one row per actual received column** with: ordinal; exact case-sensitive physical column name; mapped logical field or explicitly source-only lineage field; approved source evidence; source-cell type/format; received/generated/resolved/derived disposition; applicability; and required/optional/conditional source-cell rule where established. It must identify fields generated/resolved/derived **outside** the header and explain each logical target's provenance. Store the exact header bytes including final LF; header order/spelling changes require a new PD-02 schema ID. The source-owner/Data Owner simulated review evidence required by G3 remains Pending confirmation. Until this table is complete and approved for a section, `header_status = PENDING_CONFIRMATION` and the section **fails closed**.

No Python code, dataset or database object is created by this annex.
